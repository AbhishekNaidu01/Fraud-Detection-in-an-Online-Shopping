# 🛡️ Fraud Detection System in Online Shopping

## 📌 Project Overview
The Fraud Detection System is a Java-based application designed to identify potentially fraudulent transactions in an online shopping environment.  
The system analyzes transaction details using predefined validation rules and logical checks to flag suspicious activities.

This project demonstrates strong understanding of **Core Java, Object-Oriented Programming (OOPS), data validation, exception handling, and problem-solving skills**.

## ✨ Key Features

---

## ⚙️ How the System Works

1. User enters transaction details:
   - User ID
   - Transaction Amount
   - Payment Method
   - Billing Address
   - Shipping Address

2. System applies fraud detection rules such as:
   - Large transaction amount check
   - Rapid repeated transactions
   - Address mismatch detection
   - Invalid payment details

3. If any suspicious condition is detected:
   - Transaction is flagged as "Potential Fraud"
   - Alert message is generated
